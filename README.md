# Drone Pilot Forge

crie um app para piloto de drone, onde tenha a pasta de documentos do piloto e do drone. O app precisa ter dados de clima, dados do gps, sinal de gps, ventos medio, rajadas de ventos, precipitação do clima, visibilidade, indice KP, unidade relativa do ar, satelites, aurora kp8 , nascer e por do sol
